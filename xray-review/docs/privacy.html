Privacy & data flow

Review images and annotations stay on this device and are not uploaded by this application.

  • GitHub Pages hosts application code plus password-encrypted public-source research X-rays.
  • Passwords are shared with doctors separately and are not stored in the website code.
  • After unlock, annotations are stored in browser IndexedDB on your device.
  • There is no upload API or analytics. You export a feedback ZIP yourself.
  • Encryption is a simple convenience barrier, not a clinical confidentiality control.
  • This deployment must not be reused for private clinical/PACS images or datasets whose licences prohibit redistribution.

Assume the website code and encrypted packages can be copied publicly. Returned annotations and owner passwords must remain off the site.
